# 🎨 Vector-based Art Recommendation Model (Two-Tower, 512D)

이 프로젝트는 유저의 행동 로그와 작품 콘텐츠를 **벡터 공간에서 정렬**하여  
“유저가 다음에 볼 가능성이 높은 작품”을 추천하는 모델입니다.

---

## 1. Goal

- 유저 취향(personality_vector)과 작품 정보(piece_vector)를 이용
- 실시간 추천 가능
- 신진 예술가(Cold Start 아이템) 대응
- 이미지/영상 원본 없이 **벡터 기반 추천**

---

## 2. Assumption (Preprocessing Done)

본 모델은 **전처리 이후 단계만 담당**합니다.

이미 준비된 입력 데이터:

| 이름 | 설명 | 차원 |
|----|----|----|
| personality_vector | 유저 행동 로그 기반 벡터 | `[P]` |
| piece_vector | 작품 콘텐츠(CLIP 등) 벡터 | `[512]` |
| category_vector | 다중 카테고리 임베딩 결과 | `[512]` |
| user_id | 유저 식별자 | scalar |
| item_id | 작품 식별자 | scalar |

---

## 3. Model Architecture

### Two-Tower Retrieval Model

#### User Tower
- Input: `user_id`, `personality_vector`
- Output: `u ∈ R^512`

#### Item Tower
- Input: `item_id`, `piece_vector`, `category_vector`
- Output: `v ∈ R^512`

> 모든 임베딩 차원은 **512로 통일**

---

## 4. Training Objective

모델이 학습하는 단 하나의 목표:

> **유저 벡터 u가,  
> 실제로 반응한 아이템 벡터 v와 가장 가깝도록 정렬**

---

## 5. Training Method

### In-batch Negatives Retrieval

For batch size B:

1. 유저 벡터 `u[B,512]` 생성
2. 정답 아이템 벡터 `v[B,512]` 생성
3. 점수 행렬 계산  
   `scores = u @ v.T` → `[B,B]`
4. 정답은 대각선 (`label = arange(B)`)
5. CrossEntropyLoss로 학습
6. Backpropagation + Optimizer Step

---

## 6. Why Dot Product?

- 매우 빠른 계산
- ANN(Vector DB)와 직접 연결 가능
- 대규모 추천 시스템의 표준 방식

---

## 7. Output

- 내부: 유저 벡터 / 아이템 벡터
- 외부(API): 추천 작품 ID + 점수

```json

  {"item_id": "Art-5510", "score": 0.92},
