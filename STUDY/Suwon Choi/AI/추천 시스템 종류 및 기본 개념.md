# 추천 시스템 (Recommendation System) 개요

추천 시스템은 사용자의 과거 행동 데이터나 아이템의 속성을 분석하여, **사용자가 선호할 만한 아이템을 예측하고 제안**하는 정보 필터링(Information Filtering) 기술입니다.

---

## 1. 주요 추천 알고리즘의 종류

데이터를 활용하는 방식에 따라 크게 콘텐츠 기반, 협업 필터링, 하이브리드 등으로 나뉩니다.

### ① 콘텐츠 기반 필터링 (Content-Based Filtering, CBF)
사용자가 과거에 좋아했던 아이템과 **'속성(Feature)'이 비슷한 아이템**을 추천하는 방식입니다.

* **작동 원리:** 아이템의 텍스트, 장르, 태그 등을 분석하여 유사도 계산
* **예시:** "당신이 '아이언맨(액션/SF)'을 보았으니, '어벤져스(액션/SF)'도 좋아할 것입니다."
* **장점:**
    * 다른 사용자의 데이터가 필요 없음 (초기 사용자에게 유리)
    * 추천의 이유를 설명하기 쉬움 (e.g., "액션 장르라서 추천")
* **단점:**
    * **Filter Bubble:** 사용자가 이미 아는 장르만 계속 추천되어, 새로운 분야 발견이 어려움

### ② 협업 필터링 (Collaborative Filtering, CF)
사용자와 아이템 간의 **'상호작용 데이터(평점, 구매 이력)'**를 기반으로 추천합니다. "취향이 비슷한 사람들은 다른 아이템도 비슷하게 평가할 것"이라는 가정에 기초합니다.

#### A. 사용자 기반 (User-Based CF)
* **개념:** 나와 취향이 비슷한 **다른 사용자(Neighbor)**가 좋아하는 아이템을 추천
* **예시:** "A님과 취향이 비슷한 B님이 이 상품을 샀습니다."

#### B. 아이템 기반 (Item-Based CF)
* **개념:** 사용자가 과거에 선호한 아이템과 **함께 자주 소비된 아이템**을 추천 (커머스에서 주로 사용)
* **예시:** "이 노트북을 산 사람들이 보통 이 마우스도 같이 샀습니다."

#### C. 잠재 요인 모델 (Latent Factor Model) - 행렬 분해
* **개념:** 사용자와 아이템의 상호작용 행렬을 분해하여 숨겨진 특성(Latent Factor)을 찾아냄
* **특징:** 빈 공간(아직 평가하지 않은 항목)의 값을 예측하는 데 탁월함 ($R \approx P \times Q^T$)

### ③ 딥러닝 기반 추천 (Deep Learning-based)
* **Neural CF:** 행렬 분해를 신경망으로 대체하여 비선형적 관계 학습
* **Session-based (RNN/Transformer):** 사용자의 **행동 순서**를 학습하여 "다음에 무엇을 클릭할지" 예측 (예: YouTube, TikTok)

## 2. 핵심 개념 및 용어

### 1) 피드백 (Feedback) 데이터

| 종류 | 설명 | 예시 | 특징 |
| :--- | :--- | :--- | :--- |
| **명시적 피드백**<br>(Explicit) | 사용자가 호불호를 **직접** 표현 | 별점, 좋아요/싫어요 | 정확하지만 데이터 양이 적음 |
| **암시적 피드백**<br>(Implicit) | 행동을 통해 **간접** 유추 | 클릭, 체류 시간, 구매, 검색 | 데이터 양이 방대하지만 노이즈 가능성 있음 |

### 2) 콜드 스타트 (Cold Start)
* **문제:** 신규 사용자나 신규 아이템은 **과거 이력이 없어서** 추천이 불가능하거나 추천되지 않는 현상
* **해결:** 가입 시 선호 장르 조사, 인기도 기반 추천(Most Popular) 제공 등

### 3) 유사도 측정 (Similarity Measure)
* **코사인 유사도 (Cosine Similarity):** 두 벡터 사이의 각도를 이용하여 유사도 측정 (가장 보편적)
    $$\text{similarity} = \cos(\theta) = \frac{A \cdot B}{\|A\| \|B\|}$$
* **자카드 유사도 (Jaccard Similarity):** 집합 간의 교집합 비율 계산

## 3. 요약 비교

| 구분 | 콘텐츠 기반 (CBF) | 협업 필터링 (CF) |
| :--- | :--- | :--- |
| **기반 데이터** | 아이템의 속성 (텍스트, 장르 등) | 사용자-아이템 상호작용 (평점 등) |
| **핵심 가정** | "과거에 좋아한 것과 비슷한 것" | "비슷한 사람들은 취향도 비슷함" |
| **장점** | 신규 아이템 추천 용이 | 의외의 발견(Serendipity) 가능 |
| **단점** | 필터 버블 (유사한 것만 추천) | 콜드 스타트 문제, 데이터 희소성 |
