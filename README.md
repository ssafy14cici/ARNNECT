## 학습 자료 업로드 방식

<aside>

매일 까먹지말고 업로드 하기~~~~~~~~( •̀ ω •́ )y

</aside>

### 깃 컨벤션
```
날짜_이름
ex :  260115_이수진
```

### 폴더 구조

```jsx
├── 이름/
│   ├── 날짜/
│       ├── 카테고리/
│       │   └── 파일
```

### 예시

```jsx
├── Sujin Lee/
│   ├── 20260101/
│       ├── BE/
│       │   └── 1. 스프링부트 초기 세팅.md
│       │   └── 2. 스프링부트 시작하기.md
│       ├── CICD/
```
