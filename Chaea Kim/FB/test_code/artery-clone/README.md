# 🎨 Arnnect

본 프로젝트는 "하나의 예술 경험을 다음 경험으로 잇는 서비스"라는 컨셉을 시각적으로 극대화하기 위해, 단순한 웹 페이지 구성을 넘어 **3D 공간감**과 **유기적인 이동감**을 구현하는 데 집중했습니다.

## 💡 Design Motivation & Feedback

* **디자인적 목표:** 평면적인 카드 나열이 아닌, 입체감(Depth)과 동적인 이동감(Movement)을 통해 사용자가 마치 갤러리 내부를 유영하는 듯한 경험을 제공하는 것입니다.

## 🛠 주요 구현 기술 (Technical Highlights)

### 1. 3D 공간감과 입체감 (CSS 3D Transform)


**구현 원리:** `preserve-3d` 속성과 `translate3d`, `rotateX/Y`를 활용하여 웹 화면에 가상의 3D 공간(`world`)을 구축했습니다. 



**디테일:** 각 전시실(`roomWrap`)을 X축으로 배열하고, 벽면(`side--back`, `left`, `right`)에 따라 이미지를 배치하여 사용자가 깊이감을 느낄 수 있도록 설계했습니다. 



### 2. 시점 추종 및 인터랙티브 이동 (Dynamic Camera Motion)


**구현 원리:** 마우스 포인터의 위치에 따라 카메라 시점이 미세하게 움직이는 `camRotX/Y` 로직을 적용했습니다. 



**효과:** 사용자의 시선(커서)을 따라 화면이 부드럽게 반응하며, 정적인 이미지가 아닌 살아있는 입체 공간의 느낌을 줍니다. 



### 3. "흐름"을 형상화한 전이 효과 (Travel Animation)


**구현 원리:** 방과 방 사이를 이동할 때 단순히 화면이 바뀌는 것이 아니라, 뒤로 살짝 멀어졌다가(`travelZ`) 비틀어지며(`travelYaw`) 옆방으로 흘러가는 `travel` 함수를 구현했습니다. 



**피드백 반영:** "관심이 흐르는 길"이라는 서비스의 본질을 담기 위해 `cubic-bezier` 가속도를 활용하여 유기적이고 리드미컬한 이동감을 완성했습니다. 



## 📂 핵심 코드 구조


**`index.css`**: `--worldX`, `--travelZ`, `--travelYaw` 등의 커스텀 변수를 통해 3D 변환 로직을 선언적으로 관리합니다. 


* **`App.jsx`**: `ROOM_SPACING`을 활용한 방 배치 로직과 `requestAnimationFrame`을 이용한 부드러운 카메라 틱(tick) 연산을 담당합니다.
