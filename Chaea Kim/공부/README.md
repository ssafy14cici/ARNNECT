미술 큐레이션 웹앱 프로젝트를 위한 피그마 기초 역량 강화 기록입니다.

## 📅 학습 내용 요약 (1/12-14)

### 1. 피그마 생태계의 이해

* **Figma (Design/Prototyping):** 고도화된 UI/UX 디자인 및 프로토타입 제작.
* **FigJam (Ideation):** 프로젝트 초기 브레인스토밍, 사용자 흐름(User Flow) 및 기획 단계 활용.

### 2. 효율적인 워크플로우 (Workflow)

* **작업 프로세스:** `도구 선택` → `요소 생성/선택` → `우측 패널 속성 설정` 순의 일관된 작업 흐름 습득.
* **정밀한 배치:** 픽셀 격자(Pixel Grid) 및 스내핑(Snapping) 기능을 활용하여 디자인 요소를 배치하고, Export 시 발생할 수 있는 소수점 오류 방지.

### 3. 구조적 디자인 설계 (Hierarchy)

피그마 파일 내 요소들을 논리적으로 관리하기 위한 올바른 계층 구조를 학습했습니다.

> **File > Page > Canvas > Section > Frame > Element**

* **Canvas vs Frame:** 디자인이 그려지는 무한한 공간인 캔버스와, 실제 UI의 컨테이너 역할을 하는 프레임의 차이 이해.
* **주요 단축키:** `F`(Frame 생성), `Ctrl + D` 또는 `Alt + Drag`(요소 복제).

### 4. 핵심 기능 및 협업 도구

* **Components (컴포넌트):** 버튼, 아이콘 등 반복되는 요소를 등록하여 재사용성을 높이고 디자인 일관성(Consistency) 유지.
* **Dev Mode (개발자 모드):** '준비 완료' 표시 및 속성 정보를 코드 형태로 제공하여 디자이너-개발자 간의 커뮤니케이션 간극 해소.

## 📅 학습 내용 요약

### 1. 피그마 기초 조작 및 단축키

* **전체 단축키 확인:** `Ctrl` + `Shift` + `?` 를 통해 피그마 내의 모든 단축키를 확인할 수 있습니다.
* **딥 셀렉트 (Deep Select):** 프레임 안에 깊숙이 위치한 요소를 선택할 때 `Ctrl` + `커서 클릭`으로 즉시 선택이 가능합니다.
* **편집 모드 진입:** 요소를 `더블 클릭`하거나 `Enter`를 눌러 세부 수정 모드로 진입하며, `Esc`나 `Done` 버튼으로 완료합니다.

### 2. 쉐입(Shape) 도구 활용 및 조작법

도구 선택 후 `Shift`와 `Alt` 조합을 활용하면 정밀한 드로잉이 가능합니다.

| 도구 | 단축키 | 특징 및 조작 디테일 |
| --- | --- | --- |
| **Rectangle** | `R` | `Shift`: 정사각형 / `Alt`: 중심점 기준 생성 / `Radius`: 모서리 곡률 조절 |
| **Ellipse** | `O` | 부채꼴 도구(Arc)를 활용해 원의 각도 조절 및 파이 차트 형태 제작 가능 |
| **Line / Arrow** | `L` | 시작점부터 드래그하여 생성. 화살표는 끝점의 헤드 유무 차이 |
| **Polygon** | (메뉴) | 기본 삼각형 생성. `Count`를 조절해 다각형 제작 (최소 3개) |
| **Star** | (메뉴) | 꼭짓점 개수, 내부 반경(Inner Radius), 모서리 곡률 조절 가능 |

* **공통 조작:** `Shift`를 누른 채 회전하면 지정된 각도(15도 단위)로 스냅이 걸리며 회전합니다.

### 3. 디자인 패널(Design Panel) 상세 설정

우측 패널을 통해 요소의 수치와 정렬을 정밀하게 제어합니다.

* **정렬(Alignment):** 부모 요소(프레임)를 기준으로 정렬합니다. 2개 이상의 요소 선택 시 간격을 동일하게 맞추는 **Tidy up** 기능을 활용할 수 있습니다.
* **좌표 및 사이즈:** * `X, Y`: 프레임 내 절대 좌표값.
* `W, H`: 크기 조절. **사슬 아이콘(Constrain Proportions)** 활성화 시 가로세로 비율을 유지합니다.


* **회전 및 곡률:**
* 숫자를 직접 입력하거나 드래그하여 조절 가능합니다.
* **Corner Smoothing:** 직선과 곡선 사이의 연결을 더 부드럽게 처리하여 iOS 스타일의 고급스러운 곡면을 구현합니다.
